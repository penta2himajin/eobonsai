Chosen because it is best or equal on every workload tested, not just this one:

workload                            none   default(12/48)   tuned(6/128)
full-file rewrite (above)           28.6       138.5           194.3    (+40% vs default)
explain + quote 3 functions         28.3        42.7            44.1    (+3% vs default)
plain chat, no context reuse     28.43       ~28.3           ~28.3    (-0.5%)

Greedy equivalence: with -n 64 temp 0 on the rewrite prompt, the generated text under
--spec-type none and under the tuned params is byte-identical (32 lines, 0 differing).
An earlier report of a 1-line difference was the loading spinner, not output.

Served path, llama-server with the tuned params wired into config/rt3060.env, same prompt,
reasoning_effort "none": 225.40 t/s, 248 drafts, 248 accepted (100%), wall 5.3 s.
(CLI 194.3 and served 225.4 differ because the server had the prompt cached.)

Mechanism: each accepted draft buys tokens per weight pass. Longer drafts win because a
matched n-gram span is emitted in one verification; the fork's default draft of 48 leaves
most of a long copied span to be produced one token at a time.
